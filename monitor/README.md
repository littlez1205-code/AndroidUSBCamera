# USB 显示器

把手机或平板变成电脑的显示器：电脑 HDMI → HDMI 采集卡 → OTG 线 → 手机/平板。
App 只做一件事：全屏显示采集卡的画面，优先 60 帧。

## 安装

1. 打开本仓库的 **Releases** 页面，找到「USB 显示器（最新版）」(`monitor-latest`)。
2. 用手机浏览器下载 `USB-Display.apk` 并安装（需要允许“安装未知来源应用”）。
3. 以后有新版本，直接覆盖安装即可。

也可以在 **Actions → USB 显示器 APK** 里任意一次构建的 Artifacts 下载。

## 使用

1. 采集卡插到电脑的 HDMI 口，再用 OTG 线插到手机/平板。
2. 第一次会询问「相机」权限（安卓系统规定读取 USB 视频设备需要这个权限）和 USB 访问权限，都选允许。
   勾选「默认打开此应用」后，以后插上采集卡会自动打开 App。
3. 在电脑的显示设置里，这块屏幕会显示为采集卡的名字，可以选「扩展」或「复制」。
4. 点一下屏幕打开菜单（几秒后自动隐藏）：
   - **分辨率**：默认「自动」，会挑能跑满 60 帧的最高分辨率（最高 1080p）。
   - **画面**：保持比例（留黑边）或拉伸铺满。
   - **方向**：横屏，或竖屏（需要在电脑显示设置里把这块屏的方向改成「纵向」，
     画面如果是倒的，就换另一个竖屏方向）。
   - 菜单上方显示实际帧率：「采集」是采集卡送来的帧数，「显示」是屏幕实际画出的帧数。

## 闪退了怎么办

「闪退」就是 App 自己突然关掉、退回桌面。重新打开 App 时会自动弹出「上次闪退的原因」，
点「复制」把内容发出来即可（里面有手机型号、安卓版本、采集卡型号和出错位置，没有个人信息）。
同时说明一下是在哪一步闪退的：刚打开、插上采集卡、允许权限、出画面后，还是切换菜单选项时。

## 关于 60 帧

- 能不能 60 帧首先取决于采集卡：很多 USB 2.0 采集卡在 1080p 下只有 30 帧，720p 才有 60 帧。
  这种卡在「自动」模式下会选 720p60；想要 1080p 可以在「分辨率」里手动选（会是 30 帧）。
- USB 3.0 采集卡需要手机/平板的接口也支持 USB 3.0，才能用到「无压缩」模式。
- 菜单里「显示」帧数明显低于「采集」帧数时，说明这台设备解码跟不上，可以换低一点的分辨率。

## 实现说明

- 画面直接解码进屏幕的显示缓冲区，不经过 OpenGL、没有中间拷贝，只保留最新一帧，
  不会越拖越慢（见 `libuvc` 的 `UVCPreview::draw_low_latency`）。
- MJPEG 用 libjpeg-turbo（NEON 加速）解码；无压缩的 YUY2 用 NEON 转成 RGB。
- 签名密钥 `signing/usbdisplay.jks` 放在仓库里，方便新版本直接覆盖安装；只适合个人自用。
