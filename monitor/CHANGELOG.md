# USB 显示器 v1.0

第一个正式版本：把安卓手机 / 平板通过 HDMI 采集卡当作电脑的显示器使用。

## 下载

- `USB-Display-v1.0.apk`：安装包，可以直接覆盖安装之前的测试版本。
- `native-symbols.zip`：这个版本带函数名的原生库，只用于分析闪退报告，不需要安装。

## 功能

- 插上采集卡自动打开，全屏、常亮，自动选择能跑满 60 帧的最高分辨率（最高 1080p）
- 点屏幕打开菜单：分辨率、画面（保持比例 / 拉伸铺满 / 原始像素 1:1）、横屏 / 竖屏、诊断信息
- 菜单实时显示采集 / 显示帧率，以及每帧的解码时间和等屏幕时间
- 切到后台、锁屏、拔插采集卡后自动恢复
- 省电：画面没变化时跳过解码；没有信号 2 分钟后按系统设置息屏
- 闪退后再次打开会显示原因，可以一键复制；「诊断信息」记录采集卡的传输参数和统计

## 底层修复（libuvc / UVCCamera）

- 设置分辨率时忽略了帧率，支持 60 帧的采集卡只跑 30 帧
- 停止传输时的三处崩溃（使用已销毁的锁）：取消传输等待不足、拔线后跳过清理、关闭时状态回调未注销
- 批量传输：一次申请整帧大小的缓冲区，超过 usbfs 内存上限导致无法开始传输；改为 64 KiB 分块并重新拼帧
- USB 3.0 等时传输：每个服务周期的数据量取自 SuperSpeed 端点伴随描述符
- 去掉了 USB 事件线程里逐包发出的同步控制请求
- 新的低延迟显示路径：只保留最新一帧，MJPEG 直接解码到屏幕缓冲区，YUY2 用 NEON 转换

## 已验证

- 设备：MEIZU 21 Pro（Android 16）、一台安卓平板
- 采集卡：UGREEN 25854（批量传输，MJPEG，1920×1080 @ 60 帧）
- 尚未在真机验证：USB 3.0 等时传输的采集卡、无压缩 YUY2 格式的采集卡
